# Photoaffinity Labelling Proteomics Analysis Using R

## Overview

This repository contains R scripts for the analysis and visualisation of mass spectrometry-based photoaffinity labelling (PAL) proteomics data.

The scripts are designed to identify proteins selectively labelled by a photoaffinity probe and assess competition by the corresponding unlabelled compound.

Three experimental conditions are compared:

- **DMSO:** Vehicle control without photoaffinity probe.
- **Probe:** Sample treated with photoaffinity probe.
- **ProbeComp:** Sample treated with photoaffinity probe and excess unlabelled competitor to differentiate specific and non-specific labelling.

The `plot_label_vs_comp_PAL_v2.R` script calculates two independent enrichment measurements (the Winter method):

1. **Labelling:** log2(Probe/DMSO), indicating the extent of probe-dependent protein labelling.
2. **Competition:** log2(Probe/ProbeComp), indicating the extent to which labelling is reduced by unlabelled competitor.

These values are plotted against one another to identify proteins exhibiting both probe-dependent labelling and competition-dependent enrichment. Significantly enriched proteins can be identified using user-defined thresholds, including a specified number of median absolute deviations (MAD) above the median enrichment.

The `venn_diagram.R` script compares protein identifications or significant hits across two to five independent datasets, generating Venn diagrams to identify proteins reproducibly detected or enriched across biological replicates.

The scripts are written in R and can be run using RStudio. The `install_packages.R` script should be run first to install the required R packages.

## Usage

Each script contains a user-configurable section near the beginning, where input files, data columns and analysis parameters can be specified.

To perform an analysis:

1. Open the relevant `.R` script in RStudio.
2. Set `data_path` to the directory containing the input data.
3. Specify the input filename (`.xlsx` or `.csv`, as supported by the script) and, where applicable, the Excel worksheet.
4. Update the column-name mappings to match the input dataset.
5. Adjust the analysis parameters as required, following the comments within the script.
6. Run the script using **Source** in RStudio.

Interactive enrichment plots can be viewed in RStudio, and processed results can be exported to Excel.

The `venn_diagram.R` script uses Excel results generated by the PAL enrichment analysis and can compare either all identified proteins or proteins classified as significant hits.

## Enrichment analysis

Two enrichment measurements are calculated:

**Labelling:**

`log2FC = log2(Probe intensity / DMSO intensity)`

**Competition:**

`log2FC = log2(Probe intensity / ProbeComp intensity)`

Higher values indicate greater probe-dependent labelling and competition-dependent enrichment, respectively.

Proteins exhibiting high enrichment in both comparisons are considered potential compound-interacting proteins.

Enrichment thresholds can be specified as a fixed log2 fold-change, mean plus a multiple of the standard deviation (SD), or median plus a selected number of median absolute deviations (MAD).

We recommend using four MAD above the median (`median+4MAD`) for both enrichment measurements as an initial threshold.

Missing intensity values can optionally be imputed using a value slightly below the lowest detected intensity, approximating the limit of detection (LOD).

The script also allows imputation to be restricted to the DMSO control.

## Comparison of independent experiments

The `venn_diagram.R` script compares protein identifications across up to five datasets.

Two analysis modes are available:

- `mode = "hits"` compares proteins identified as significant hits.
- `mode = "all"` compares all proteins included in the input datasets.

The script generates a Venn diagram showing the overlap between datasets and exports a combined protein identification table to Excel. As PAL can be noisy we recommend using at least three biological replicates.

## Data interpretation

Probe-dependent labelling indicates that a protein is recovered following treatment with the photoaffinity probe, while competition-dependent enrichment indicates that this recovery is reduced by the unlabelled compound.

Proteins showing both characteristics are potential compound-interacting proteins, although these measurements do not necessarily establish direct binding.

Missing intensity values can influence calculated enrichment, particularly where proteins are detected in one experimental condition but not another. Results involving imputed measurements should therefore be interpreted cautiously.

Reproducible enrichment across independent biological replicates provides additional evidence supporting potential compound–protein interactions.
